📝 Descrição do Projeto
Este projeto foi desenvolvido para explorar e visualizar um banco de dados de notas e avaliações de filmes. Inspirado na formação de Data Science da Alura, o objetivo foi transformar dados brutos em insights visuais, permitindo comparar médias de avaliações, popularidade e distribuições estatísticas de forma dinâmica.

Como estudante de Análise e Desenvolvimento de Sistemas, foquei na criação de uma interface limpa que facilite a leitura dos dados para usuários que não são da área técnica.

🛠️ Tecnologias e Ferramentas
- Python: Linguagem principal para o processamento dos dados.

- Streamlit: Framework utilizado para construir a interface web interativa.

- Pandas: Manipulação, filtragem e agregação dos dados.

- Matplotlib/Seaborn: Geração de gráficos estatísticos e visuais.

🚀 Funcionalidades
-Análise Comparativa: Visualização de médias de notas por filme.

-Filtros Dinâmicos: Possibilidade de explorar diferentes títulos do dataset.

-Visualização Estatística: Gráficos de barras e distribuições que ajudam a entender o comportamento das avaliações dos usuários.

⚙️ Como executar localmente
Caso queira rodar o projeto em sua máquina:

Clone o repositório:

Bash
git clone https://github.com/seu-usuario/dashboard-filmes-streamlit.git
cd dashboard-filmes-streamlit
Instale as dependências:

Bash
pip install streamlit pandas matplotlib seaborn
Execute a aplicação:

Bash
streamlit run main.py
